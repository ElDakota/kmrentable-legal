Privacy Policy - KM Rentable

Last updated: May 11, 2026

KM Rentable is designed to analyze transport platform offers shown on the user’s screen in real time in order to estimate profitability.

What the app does

KM Rentable uses screen capture permission to read offer information such as amount, time, and distance, and uses that information to calculate estimated profitability.

Data access and use

  • The app may access screen content only after the user explicitly grants screen capture permission.
  • The app processes offer information in real time to calculate estimated profitability.
  • The app uses internet connection to verify app version support and related service availability.

Data collection and sharing

  • KM Rentable does not create user accounts.
  • KM Rentable does not sell user data.
  • KM Rentable does not intentionally collect personal data for marketing purposes.
  • KM Rentable does not share screen content with third parties for advertising or profiling.

Storage and retention

Screen content is processed for immediate analysis. The app is designed to use the information only while needed for the calculation flow. Configuration values such as cost per kilometer or tax retention may be stored locally on the device to improve the user experience.

User control

  • The user can stop screen capture at any time from the app or from Android system controls.
  • The user can uninstall the app at any time.

Security

We take reasonable measures to limit data use to the functionality described above.

Children

KM Rentable is not directed to children.

Contact

If you have questions about this Privacy Policy, contact the developer through the contact information provided in the Google Play listing.
